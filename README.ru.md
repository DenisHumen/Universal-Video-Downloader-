## Чем оно лучше

- **Работает там, где другие сдаются.** Движок yt-dlp знает 1800+ сайтов. Если сайт ему незнаком, приложение читает страницу, а потом проигрывает её в скрытом браузере и ловит поток в момент загрузки, вместе с заголовками, которые требует сервер.
- **Говорит, что вы получите, ещё до нажатия.** Кнопки качества берутся из того, что у видео есть на самом деле, а «лучшее» объясняет, что это значит: `2160p60 · HDR · MP4 · ≈ 1.2 GB`.
- **Может вести сериал целиком.** Поставьте сериал на слежение, и каждая новая серия скачается, переименуется, уедет на сетевую шару и придёт уведомлением в Telegram, даже если приложение не открыто.
- **Без аккаунта, рекламы и телеметрии.** Всё работает на вашем компьютере. Интерфейс на русском и английском.

| Платформа | Скачать | |

При первом запуске приложение скачает движок yt-dlp (около 30 МБ) и дальше само будет его обновлять; ffmpeg уже встроен. Вставьте ссылку, выберите качество и нажмите **скачать**. Файлы попадают в папку *Загрузки*.

### Linux

Ubuntu, Debian, Mint:

```bash
curl -fsSL https://denishumen.github.io/Universal-Video-Downloader-/uvd.gpg | sudo tee /usr/share/keyrings/uvd.gpg > /dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/uvd.gpg] https://github.com/DenisHumen/Universal-Video-Downloader-/releases/latest/download/ ./" | sudo tee /etc/apt/sources.list.d/universal-video-downloader.list
sudo apt update && sudo apt install universal-video-downloader
```

Fedora, RHEL, openSUSE (в openSUSE файл кладётся в `/etc/zypp/repos.d/`):

```bash
sudo curl -fsSL -o /etc/yum.repos.d/universal-video-downloader.repo https://denishumen.github.io/Universal-Video-Downloader-/universal-video-downloader.repo
sudo dnf install universal-video-downloader
```

Оба репозитория подписаны, обновления приходят вместе с системными (`sudo apt upgrade`, `sudo dnf upgrade`).

### macOS: «приложение повреждено и не может быть открыто»

**Это не так.** Сборки не подписаны платным сертификатом Apple, и macOS пишет эту фразу про любое неподписанное приложение, которое поместила в карантин. Скопируйте приложение в **Программы** и один раз выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/Universal Video Downloader.app"
```

Эта же команда напечатана в окне установки. Неподписанное приложение не может заменить само себя, поэтому на Mac оно предлагает скачать образ новой версии для вашего процессора вместо обновления на месте.

## Скачивание из терминала

```bash
uvd https://www.youtube.com/watch?v=jNQXAC9IVRw
```

`uvd` берёт лучшее качество, какое есть у видео, и сохраняет его в *Загрузки* (или в папку из настроек приложения), с тем же движком, ffmpeg, cookies и прокси, что и приложение. `uvd -a <ссылка>` сохраняет только звук, `-o <папка>` сохраняет в другое место, несколько ссылок скачиваются по очереди. Если ссылку распознать не удалось, `uvd` так и скажет и предложит открыть приложение, у которого больше способов найти поток; код выхода при этом 2, чтобы скрипты могли это отличить.

- **Linux, apt / dnf / `.deb` / `.rpm`:** `uvd` ставится вместе с приложением.
- **Linux, AppImage:** запускайте AppImage с `--cli`, например `alias uvd='~/Applications/Universal-Video-Downloader.AppImage --cli'`.
- **macOS:** один раз добавьте его в PATH:

  ```bash
  sudo mkdir -p /usr/local/bin && sudo ln -sf "/Applications/Universal Video Downloader.app/Contents/Resources/bin/uvd" /usr/local/bin/uvd
  ```

| **Остальное** | Встроенные субтитры, обложки и главы, SponsorBlock, папки по сайтам, шаблон имени, ограничение скорости, прокси, две темы. |

## Сайт не работает?

1. **Включите cookies.** *Настройки → доступ и cookies*, выберите браузер, в котором вы вошли в аккаунт. Проверка возраста, вход и «только для подписчиков» перестанут мешать. Закройте этот браузер на время скачивания: он блокирует свою базу cookies.
2. **Откройте встроенный браузер.** Откройте страницу в нём и нажмите play; каждый поток появится в боковой панели. Закрытый баннер согласия или выполненный вход запоминаются.
3. **Отправьте отчёт.** Когда ссылка не сработала, приложение предложит отправить разработчику ссылку, ошибку и вывод движка. Без вашего клика ничего не уходит, а пути, пароли и токены вырезаются заранее.
4. **Или [заведите issue](https://github.com/DenisHumen/Universal-Video-Downloader-/issues/new)** со ссылкой и *выводом движка* из строки очереди.

## Подробнее

<details>
<summary><b>Как работает определение</b></summary>

<br />

Приложение пробует три способа, от самого дешёвого, и останавливается на первом сработавшем:

1. **Движок.** yt-dlp знает 1800+ сайтов: YouTube (и Shorts), TikTok, Instagram, X/Twitter, Reddit, Twitch, VK, Vimeo, SoundCloud, Bilibili и другие. Ссылки «поделиться» сначала очищаются, поэтому `youtu.be/…?si=…` и `/shorts/…` попадают в очередь одним и тем же видео.
2. **Сама страница.** JSON-LD `VideoObject`, OpenGraph `og:video`, теги `<video>`, настройки JW Player / Video.js / Plyr и один уровень iframe с плеером.
3. **Скрытый браузер.** Страница открывается в невидимом окне Chromium, плеер запускается, а манифест перехватывается из сети вместе с заголовками `Referer`, `Origin` и `Cookie`, которые нужны серверу; движок потом использует их же.

Кандидаты ранжируются (HLS ≫ DASH ≫ MP4 ≫ аудио; трейлеры, реклама и отдельные сегменты понижаются) по типу ответа, а не только по имени файла, поэтому работают и манифесты без расширения. Ссылки на потоки протухают, поэтому очередь хранит адрес *страницы* и определяет поток заново при каждом старте и повторе. Скрытый браузер отключается в *Настройки → определение*.

</details>

<details>
<summary><b>Слежение за сериалом</b></summary>

<br />

Вставьте ссылку на страницу сериала, выберите озвучку (у разных озвучек разное число серий, от неё зависит, что считать новым) и как часто проверять. Каждая новая серия проходит шаги слежения:

| Шаг | Что делает |
| --- | --- |
| **скачать** | Всегда первый, через обычную очередь: пауза, повтор и история работают как всегда. |
| **переименовать** | Шаблон с `{title}` `{season}` `{episode}` `{season2}` `{episode2}` `{quality}` `{year}` и правила замены в названии. |
| **отправить на шару** | Загрузка на SMB-шару с созданием недостающих папок; может удалить локальную копию. |
| **уведомить в Telegram** | Сообщение от вашего бота, когда серия пришла или не скачалась. |

Проверки идут по расписанию с паузами после ошибок (не чаще раза в 15 минут); **проверить сейчас** запускает проверку сразу. *Настройки → слежение* оставляют расписание работать из трея при закрытом окне и могут запускать приложение вместе с системой. Пароль SMB и токен Telegram шифруются хранилищем ключей системы. Заметки о дизайне: [`docs/automation.md`](docs/automation.md).

</details>

<summary><b>Настройки</b></summary>

<br />

| Раздел | Что там |
| --- | --- |
| **внешний вид** | Тема (ночь / день), язык (по системе) |
| **загрузки** | Папка, подпапки по сайтам, режим и качество по умолчанию, формат звука, параллельные загрузки, продолжение после перезапуска, ограничение скорости, размер плейлиста |

| **слежение** | Фоновое слежение, запуск с системой, SMB-шары, Telegram, подробный журнал |
| **доступ и cookies** | Cookies из Chrome, Firefox, Edge, Safari, Brave, Chromium, Opera, Vivaldi или `cookies.txt` |
| **сеть** | Прокси для движка и для собственных запросов приложения |
| **система** | Уведомления, слежение за буфером обмена, иконка в трее |
